Contêineres numa VM Linux, implantados por Ansible

Em termos simples: VM é um servidor virtual; contêineres são caixas isoladas dentro dele, uma por serviço; Ansible repete a instalação sempre do mesmo jeito, e uma release que falhar é trocada pela anterior em minutos.

API de catálogo como fonte de verdade; MediaMTX como servidor de vídeo; Caddy, Redis/Celery, Prometheus, Loki e Grafana
